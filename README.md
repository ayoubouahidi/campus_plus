# Campus Plus API

This project is a Django API for campus departments, clubs, members, and
club events.

## Data modeling

### Department

A department has a title. One department can have many clubs, members, and
events.

### Club

A club belongs to one department. It has:

- name and description
- a club head or president
- contact email
- meeting day, time, and location
- active status
- created and updated dates

A club name must be unique inside its department. A club can have many members
and many events.

### UserMember

`UserMember` is the campus profile for a Django user. It has:

- generated username
- first name and last name
- email from the Django user account
- year of study
- department and club
- role and event date
- profile image

A member can have one Django user account. The Django user stores the password
and is used for login.

### ClubEvent

An event belongs to a department and can belong to a club. It has:

- name and description
- start and end date
- location
- status
- event image
- created and updated dates

The event status can be `planned`, `ongoing`, `completed`, or `cancelled`.

Images must be a real JPEG, PNG, or WEBP file and must be smaller than 2 MB.

## Filtering and search

Club events can be filtered by department:

```text
GET /api/club-events/?department=1
```

They can also be filtered by a word in the event name or description:

```text
GET /api/club-events/?category=football
```

Both filters can be used at the same time:

```text
GET /api/club-events/?department=1&category=football
```

The event endpoint also supports search. Search checks the event name,
description, and department title:

```text
GET /api/club-events/?search=technology
```

Departments can be searched by title:

```text
GET /api/departments/?search=computer
```

## Main API endpoints

```text
POST /api/signup/
GET  /api/departments/
GET  /api/clubs/
GET  /api/club-events/
GET  /api/members/
```

Signup needs first name, last name, email, department, year of study, and
password. The username is generated by the server and a token is returned.

Only an admin can create, update, or delete members and clubs. An admin or the
head of a club can create events for that club.

## How to run and test

Activate the virtual environment:

```bash
source .ven/bin/activate
```

Install the packages:

```bash
python -m pip install -r requirements.txt
```

Run the database migrations:

```bash
python manage.py migrate
```

Run all tests:

```bash
python manage.py test
```

The tests cover the data filters, signup, generated usernames, image checks,
club events, and permissions. The result should finish with `OK`.

Check that no migration is missing:

```bash
python manage.py makemigrations --check
```
